## Writing Principles

- Axes in figures should be clearly labeled and start at zero if appropriate.
- Avoid unnecessary axes, tick marks, or grid lines for clarity.
- Different symbols or markers should be used to distinguish different data series.
- Select colours that are distinguishable, including for colour blind readers.
- Avoid using colours that are hard to see (e.g., yellow) or differentiating only by shades of a single colour.
- Consider greyscale or carefully selected colour palettes (such as those from tools like colorbrewer).
- Use colour thoughtfully and only when it adds value to data interpretation, especially with accessibility in mind.
